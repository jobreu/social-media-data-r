# Course Materials *Collecting and Analyzing Social Media Data with R*

This repository contains the materials for the slides and an accompanying book for the coding part of the seminar [*Collecting and Analyzing Social Media Data with R*](https://campus.uni-due.de/lsf/rds?state=verpublish&status=init&vmfile=no&publishid=432257&moduleCall=webInfo&publishConfFile=webInfo&publishSubDir=veranstaltung) taught in the summer term of 2026 in the [Political Science BA program](https://www.uni-due.de/politik/ba_political_science.php) at the [University of Duisburg-Essen](https://www.uni-due.de/en/).

*Note 1*: The course and the accompanying materials are still under development. The content will be updated and expanded as the course progresses.
*Note 2*: The course and the book are in German.
