Accounts

Zur Erinnerung: Wir benötigen:

  1. Einen TikTok-Account

  2. Einen Bluesky-Account

  3. Einen Google-Account und einen YouTube API Key. Wie Sie einen YouTube API Key erhalten, wird ausführlich in einem Tutorial von Communalytic sowie im GESIS Guide How to Collect Data with the YouTube Data API (Kohne et al., 2024) beschrieben.

Pakete

Zur Sammlung von Bluesky-, TikTok- und YouTube-Daten nutzen wir die folgenden R-Pakete: atrrr, traktok und vosonSML. Zur Nutzung von traktok brauchen wir zusätzlich noch das Paket cookiemonster.

install.packages(c("atrrr", "traktok", "vosonSML", "cookiemonster"))

Beobachtungseinheiten & Sampling

Die Beobachtungseinheiten für Bluesky und TikTok sind die Accounts von Kandidierenden zur deutschen Bundestagswahl 2025. Die Informationen zu diesen stammen aus dem Datensatz Social-Media-Konten der Kandidierenden bei der Bundestagswahl 2025 (Breuer et al., 2026).Beispiele dafür, wie Sie Accounts aus diesem Datensatz auswählen können, finden Sie im Skript get_accounts.R.

Eine weitere Quelle für Accounts ist der Datensatz Social Media Accounts (TikTok, YouTube, X/Twitter) of the Candidates in the 2025 German Federal Election (Steup et al., 2025).

Authentifizierung

Bevor wir Daten sammeln können, müssen wir uns mit unserem Bluesky-Account authentifizieren.

auth("your_user_name") # hier Ihren User Name einfügen (z.B., tmueller.bsky.social)

Sie müssen sich bei Ihrem Bluesky-Konto anmelden und ein „App-Passwort“ erstellen. Dieses Passwort müssen Sie dann in das Popup-Fenster eingeben, das nach dem Ausführen der auth()-Funktion erscheint.

Authentifizierung: Schritt 1

Wir nutzen die “Unofficial API”. Um diese nutzen zu können, müssen wir uns mit einem TikTok-Account im Browser einloggen und die Cookies für die Webseite speichern. Das geht am einfachsten mit den Browser-Plugins Get cookies.txt für Chrome bzw. cookies.txt für Firefox.

Authentifizierung: Schritt 2

Die Cookies können wir dann mit der Funktion add_cookies() aus dem Paket cookiemonster speichern. Das Argument muss dabei der Pfad sein, unter dem die .txt-Datei mit den Cookies gespeichert ist.

add_cookies(path = "./data/tiktok_cookies.txt") # Dateipfad anpassen

Authentifizierung: Check

Ob alles funktioniert hat, können wir dann mit der Funktion auth_check() aus dem Paket traktok überprüfen.

auth_check()

Sie können ausprobieren, diese lokal auf Ihrem Rechner auszuführen. YouTube

Setup

library(vosonSML)

Zur Erinnerung: Für die Sammlung von YouTube-Daten benötigen wir einen API Key für die YouTube Data API.

Authentifizierung

auth_yt <- Authenticate("youtube",
             apiKey = "your_api_key_here") # ersetzen Sie "your_api_key_here" durch Ihren tatsächlichen API Key

Videos

Die Funktion Collect() aus dem Paket vosonSML bietet die Möglichkeit, Kommentare zu bestimmten Videos zu sammeln. Dazu muss man die URLs der Videos angeben, von denen man die Kommentare sammeln möchte.

Im nachfolgenden Beispiele sammeln wir die Kommentare zu zwei exemplarischen Videos aus den Ergebnissen der Suche “Bundestagswahl 2025” auf YouTube.

video_urls <- c("https://www.youtube.com/watch?v=5A-ggbcnwcg",
               "https://www.youtube.com/watch?v=a6ZaJ38cy7U")

Rate Limits

Für die kostenfreie Nutzung der YouTube Data API gibt es bestimmte Kontingente, d.h. es gibt eine maximale Anzahl an Anfragen, die man pro Tag stellen kann. Aktuell liegt das Tageslimit bei 10.000 Anfragen pro Tag.

Je nachdem, wie viele Kommentare man sammeln möchte, kann es daher sein, dass man das Tageslimit überschreitet. In diesem Fall muss ggf. warten, bis das Tageslimit zurückgesetzt wird. Dies geschieht immer um Mitternacht Pacific Time.

Die Funktion Collect() von vosonSML zeigt einem die geschätzten API-Kosten an.
